Phần 1: Kiểm tra file lạ trong 3 bước
1. Bật hiện đuôi file: File Explorer → View → Show → File name extensions.
2. Kiểm tra tên và nguồn: Đừng tin biểu tượng file. Xác minh người gửi nếu thấy lạ.
3. Nếu đáng ngờ: Không mở, không chạy; báo IT.
Nếu thấy bang-luong-thang-10.pdf.exe, đó là file chạy chương trình, không phải PDF. Đừng mở; hãy báo IT.
Muốn tìm file .env ẩn: bật View → Show → Hidden items. Có thể nhờ IT kiểm tra nếu không quen thao tác.
Phần 2: Checklist Developer Workspace Setup
- [ ] Bật File name extensions và biết cách hiện file ẩn.
- [ ] Sắp xếp workspace thành 4 thư mục: src (mã nguồn), data (dữ liệu), docs (tài liệu), outputs (kết quả).
- [ ] Không lưu mật khẩu hoặc khóa API trong mã nguồn.
- [ ] Nếu thấy .env lạ, không mở; báo IT.
